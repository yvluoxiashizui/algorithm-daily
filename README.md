## 目录结构

```
topics/<专题>/<题目>/
├── <题目>.go         # 题解
└── <题目>_test.go    # 测试
notes/                # 知识点笔记（markdown）
ds/                   # 手写数据结构
```

## 每天流程

1. 新建 `topics/<专题>/<题目>/`，写题解 + 测试
2. `go test ./...` 确认全绿
3. `git add . && git commit -m "feat: <题目>（<思路>）" && git push`
4. 更新本 README 的进度表
