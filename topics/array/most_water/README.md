# 盛最多水的容器

- 力扣：https://leetcode.cn/problems/container-with-most-water/description/
- 日期：2026-08-21
- 难度：力扣中等，体感简单

## 题目
给定一个长度为 n 的整数数组 height 。有 n 条垂线，第 i 条线的两个端点是 (i, 0) 和 (i, height[i]) 。

找出其中的两条线，使得它们与 x 轴共同构成的容器可以容纳最多的水。

返回容器可以储存的最大水量。

说明：你不能倾斜容器

## 解题思路
双指针两边向中间逼近求面积，高度小的就进下一个再找，取最大值即为答案

## 复杂度
- 时间：O(n)
- 空间：O(1)
