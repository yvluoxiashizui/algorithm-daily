# 接雨水

- 力扣：https://leetcode.cn/problems/trapping-rain-water/description/
- 日期：2026-08-22
- 难度：困难

## 题目
给定 n 个非负整数表示每个宽度为 1 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

## 解题思路
前后缀分解
看一个地方的水分解成看左右两块木板的高度，而左边木板的高度取决于左边整块高度的最大值，高于这个最大值的会流出去，低于的会留下来，右边同理
此方法运用两个数组储存，一个存最左边到i的最大高度，即前缀最大值。一个存最右边到i的最大高度，即后缀最大值。
每块地方取前后缀最大值的最小值，减去高度即为储水量

## 复杂度
- 时间：O(n)
- 空间：O(n)（创造了两个大小为n的数组）
