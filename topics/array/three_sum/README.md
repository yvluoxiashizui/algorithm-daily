# 三数之和

- 力扣：https://leetcode.cn/problems/3sum/
- 日期：2026-08-20
- 难度：中等

## 题目
给你一个整数数组 nums ，判断是否存在三元组 [nums[i], nums[j], nums[k]] 满足 i != j、i != k 且 j != k ，同时还满足 nums[i] + nums[j] + nums[k] == 0 。请你返回所有和为 0 且不重复的三元组。

注意：答案中不可以包含重复的三元组。

## 解题思路
1. 排序，固定一个数 nums[i]，问题变成"找两数之和 = -nums[i]"（就是两数之和 II 的做法）
3. 双指针 j、k 从两端向中间逼近
4. 去重：i、j、k 三处都要跳过相同元素
5. 剪枝优化：最小的三个数和 > 0 直接结束；最大的三个数和 < 0 跳过当前 i

## 复杂度
- 时间：O(n²)（外层 O(n) × 双指针 O(n)）
- 空间：O(1)（忽略排序和返回结果）

## 出错原因
- 尚不熟悉go语法导致的语法错误
- 最后得出答案后没有去重
- 剪枝优化break和continue的原因没有想清楚，最小值相加>0,那后面的都是要大于这个值的，break，最大值<0，i还可以继续往后遍历增大，所以是continue

## 注意点
- 去重要在三处：i、j、k 都要去重
- 可以提前判断最小和最大与0的关系，优化算法
